# Native capability register

Baseline: EUV 1.4.1, Steam build **25905365**, branch **1.4-open-beta**; CMF **2.5.0**. See `baseline.json` for read-only source hashes, including the native files used by the M0 suite. Its displayed checksum belongs to the earlier modded UI run, not clean vanilla or the current runtime.

The [M0 audit](m0-probes.md) adds 38 licensed-engine assertions and 14 numerical checks of native observations, twelve monthly periods and a second-process reload. The accounts/bonds regression separately passes 114 assertions on the same runtime. **M0 remains partial:** normal UI/transport, multiplayer, complete receipt attribution, custody and compatibility gates remain open. The user confirmed that no second licensed multiplayer client is available.

Production adapter flags live in `design/tuning.json`, default false, and are compiled into permission triggers. Changing a save-game variable cannot unlock an adapter. Merely changing a flag is insufficient: the adapter implementation and evidence must be supplied before enabling it.

The published modding-digests effects/trigger/scope summaries were inspected as corroboration, not as a substitute for current-build generated documentation. The reference mathematics in `tools/ledger_reference.py` tests obligations and conservation without pretending to emulate EUV.

The [exploratory scope limitation](../tests/results/2026-10-15-native-scope-limitations.json) records a failed native-loan variable experiment, not a passed campaign. The current suite uses country-owned records. Full local logs, saves and licensed assets are excluded from the PR and release.

The [native GUI startup baseline](native-gui-diagnostics.json) classifies only the 32 signatures reproduced without BFI. [Repeatability limitations](../tests/results/2026-10-15-m0-repeatability-limitations.json) retain an extra native-label regression failure and an earlier exploration-progress failure; later passing runs do not complete the compatibility or project-outcome gates.
